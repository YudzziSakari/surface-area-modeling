Площа поверхонь: інтерактивне моделювання
Навчальний вебзастосунок для наочного дослідження поверхонь обертання та зв’язку між шкільними формулами площі й обчисленням площі через одновимірний інтеграл.
Можливості
- Перегляд тривимірних моделей сфери, циліндра, конуса та зрізаного конуса.
- Анімація утворення поверхні обертання.
- Зміна геометричних параметрів фігур за допомогою повзунків.
- Відображення аналітичного рівняння поверхні, шкільної формули площі та відповідного інтегрального запису.
- Порівняння результату за шкільною формулою з формулою, отриманою через одновимірний інтеграл.
Технології
- HTML5 — структура вебсторінки.
- CSS3 — оформлення інтерфейсу.
- JavaScript — обчислення параметрів, оновлення моделей та анімація.
- Plotly.js 2.27.0 — інтерактивна 3D-візуалізація.
- KaTeX 0.16.9 — відображення математичних формул.

1. Завантажте файл index.html із репозиторію.
2. Відкрийте його у веббраузері.
3. Оберіть геометричну фігуру, змінюйте доступні параметри та натисніть «Показати утворення фігури», щоб переглянути анімацію.
Встановлення додаткових пакетів або запуск сервера не потрібні. Для завантаження Plotly.js і KaTeX потрібне підключення до інтернету, оскільки бібліотеки підключаються через CDN.
Структура репозиторію
- index.html — вихідний код інтерактивного вебзастосунку.
- presentation.pptx — презентація проєкту.
Примітка щодо обчислень
Застосунок відображає інтегральний запис для кожної фігури, а числове значення площі обчислює за відповідною шкільною формулою. Незалежне чисельне інтегрування в коді не реалізовано; застосунок призначений для навчальної візуалізації математичного зв’язку між цими підходами.
